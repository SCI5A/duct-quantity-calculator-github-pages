# Duct Quantity Calculator

حاسبة كميات مجاري الهواء تعمل بالكامل داخل المتصفح.

## GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع `index.html`.
3. من Settings > Pages اختر GitHub Actions أو النشر من branch `main`.
4. افتح رابط GitHub Pages.

لا توجد مكتبات خارجية أو قاعدة بيانات مطلوبة.
